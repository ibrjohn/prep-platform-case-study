# Prep Platform — Case Study

A public case study for a private multi-brand tutoring platform developed across Australian senior-school markets, including HSCPrep, QCEPrep and VCEPrep.

This repository contains documentation only. The production source code, backend implementation, database structure, tutor workflows, payment logic and private business operations are not public.

## Overview

The Prep Platform was designed as more than a static tutoring website. It included public-facing tutoring/resource pages, tutor/admin workflows, session management, payment-related processes, CRM automation and API-driven platform features.

The platform was developed across multiple state-specific brands:

- **HSCPrep** — NSW-focused HSC tutoring and resource platform.
- **QCEPrep** — QLD-focused QCE tutoring and resource platform.
- **VCEPrep** — VIC-focused VCE tutoring and resource platform.

## Platform scope

The platform involved both student-facing and operational workflows, including:

- Public-facing tutoring websites
- Tutor/admin workflows
- Session management
- Payment-related processes
- Practice-question generation features
- Scheduling and customer-response workflows
- CRM automation
- Multi-brand rollout structure
- Mobile-responsive user experience
