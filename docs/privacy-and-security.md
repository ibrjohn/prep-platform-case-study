# Privacy and Security

The production implementation of the Prep Platform remains private because it contains business-critical and security-sensitive logic.

## Excluded from this public repository

The following are intentionally not included:

- Source code
- Environment variables
- API keys
- Payment secrets
- Webhook secrets
- Database credentials
- Database schema
- Tutor data
- Student data
- Admin routes
- Backend implementation details
- Private business workflows
- Internal operational processes

## Public showcase approach

This repository is designed to demonstrate product scope, platform thinking and technical responsibility without exposing private implementation details.

Only high-level documentation and safe public-facing screenshots should be included.

## Screenshot rules

Screenshots should only show public-facing pages or heavily blurred internal layouts.

Do not include screenshots containing:

- Student names
- Tutor private details
- Emails
- Phone numbers
- Payment data
- Admin URLs
- Database records
- API responses
- Internal credentials
